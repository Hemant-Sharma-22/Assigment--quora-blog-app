# 📝 Quora Blog App

A modern blog application built with **Node.js, Express, and EJS**, featuring clean UI and full CRUD functionality.

---

## 🌟 Features

- ✍️ Create posts  
- 📖 View all posts  
- 🔍 View individual post  
- ✏️ Edit posts  
- 🗑 Delete posts  
- 🎨 Modern UI with animations  
- 📱 Responsive design  

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js  
- **Frontend:** EJS, HTML, CSS  
- **Other:** UUID, Method-Override
